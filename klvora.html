Fashion Website Project



This project is a modern fashion website built with Vite + React (TSX). It integrates Neon DBMS for scalable and efficient database management and leverages n8n Agentic Automation to automatically generate and send emails to users.

The website features dynamic product listings, smooth user interactions, and an automated workflow for email notifications, making it a full-stack solution for modern e-commerce and fashion platforms.

Potential applications include e-commerce fashion stores, marketing automation, customer engagement through automated emails, and personalized shopping experiences. This project highlights the ability to combine React frontend, cloud database, and automation pipelines for real-world applications.

Check out the live website here: https://klvora.netlify.app/
